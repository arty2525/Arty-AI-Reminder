# แนวทางใช้ในห้องเรียน

ลำดับแนะนำ:

1. ครูเตรียม Ubuntu + Arty AI Reminder ให้แต่ละกลุ่ม
2. นักเรียนทดสอบ `arty-audio`
3. นักเรียนใช้ `arty-test` เพื่อพิสูจน์ระบบ scheduler โดยรอเพียง 1 นาที
4. นักเรียนใช้ `arty-reminder` และพูดคำสั่งตัวอย่าง
5. ตรวจข้อมูลด้วย `arty-list`
6. อภิปราย pipeline: Microphone → STT → Parser → SQLite → Scheduler → Speaker

คำสั่งตัวอย่าง:

```text
ตั้งเตือน วันที่ 1 กันยายน เวลา 08.00 น. ร่วมงานสถาปนา
```

ระบบจริงกำหนดการแจ้งเตือนก่อนกิจกรรม 30 นาทีจาก `src/config.py`
